# file_search
**Does:** indexes only the roots you choose (Settings > Files; none by default; Desktop/Documents/Downloads can be added individually), recursively and incrementally, on a low CPU+I/O priority thread that starts ~4 s after launch (never blocks the palette). Unchanged directories (same modification time) reuse their cached listing; the index is persisted to `%LOCALAPPDATA%\CmdPal\file-index.tsv` and loaded at start. Name search is allocation-light substring matching with relevance ranking. Exclusions: folder paths, name globs, extensions. Controls/status: pause, rebuild, clear, last scan, errors. Optional content index (off by default): whole-word match for text-like files <= 256 KB, bounded by ~2M word entries.
**Limits:** entry cap `max_entries` (default 100000) bounds RAM; symlinks are skipped; "incremental" means directory-mtime based (no live filesystem watcher).
Files: `api.rs` (public), `logic/coordinator.rs` (entry), `logic/provider.rs`, `indexing/{scanner,store,rules,content,control}.rs`.
