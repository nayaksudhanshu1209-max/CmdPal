# notes
**Window:** separate frameless window (no title bar/buttons, not topmost, taskbar button). Drag by the thin top strip, resize by the edges. Losing focus never closes it; **Esc** and **Ctrl+W** save then close (if saving fails it stays open). The palette hotkey keeps working while it is open.
**Editor:** one Windows RichEdit 5.0 surface (system Msftedit.dll - not a browser, no extra runtime). `markdown_model/model.rs` (pure, tested) analyses the text and the UI applies styles: syntax delimiters are *hidden* when the caret is outside a construct and shown *dim* while the caret is inside it. Headings, bold/italic/strike, inline code, fenced code, lists, task lists, tables (monospace), quotes, rules, links and images (styled labels; nothing is fetched). Enter continues lists/tasks/quotes and ends an empty one; paste is plain text. Notes above ~200k characters stay unformatted to keep typing fast.
**Formatting bar:** bottom, custom drawn, scrolls with the mouse wheel; click inserts/wraps at the caret and returns focus to the editor; drag a button to reorder - the order is saved per note in `notes\.toolbar\<note>.txt`.
**Storage:** `%APPDATA%\CmdPal\notes\<name>.md`. Autosave 1.5 s after the last edit and on close; saves write `.md.new` (synced), keep `.md.bak`, then atomically rename. Recovery reads `.new`/`.bak` if `.md` is missing.
**Palette:** `n <text>` (alias configurable) shows note chip: matching notes (names, then contents) and "Create note". Rename/delete notes: Settings > Notes.
Files: `api.rs`, `logic/coordinator.rs` (entry), `markdown_model/{model,assist}.rs`, `persistence/store.rs`, `ui/{note_window,richedit,toolbar}.rs`.
